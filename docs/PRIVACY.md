# 개인정보 처리 (구현 기준 메모 — 법률 문서 아님)

| 데이터 | 저장 위치 | 외부 전송 |
| --- | --- | --- |
| 옷 사진(파생본), 옷 정보, 가격, 코디, 착용 기록, 취향 | 기기(SQLite + 앱 폴더) | 없음 |
| 현재 위치 | 메모리에서 즉시 격자 번호로 변환 후 폐기 | 격자 번호(nx, ny)만 날씨 프록시로 |
| 선택한 지역 | 기기(설정에서 "기억하기" 끄면 저장 안 함) | 격자 번호만 |
| 커뮤니티 게시물 | Supabase | 사용자가 고른 사본(EXIF/GPS 제거·리사이즈), 핸들, 태그, 선택 시 거친 날씨 문구 |
| 계정 | Supabase Auth | 공급자 ID, (있으면) 이메일 — 공개 프로필에는 핸들만 |

- 백그라운드 위치 권한 없음(`app.json` 플러그인 설정 + Android `ACCESS_BACKGROUND_LOCATION` 차단).
- 사진은 OS 선택기로 사용자가 고른 1장만, `exif: false`.
- 로그(`logError`)에는 오류 분류만, URI·좌표·사진 데이터 없음.
- 기기 데이터 전체 삭제: 설정 화면. 커뮤니티 계정 삭제: 로그인 화면(스토리지 → 행 → auth 사용자).
- 출시 전: 개인정보처리방침·보호책임자·연락처 화면 필요(미구현).
