기준일 2026-10-27. 결정: DECISIONS D-017(링크), D-018(인스타그램).

## 쇼핑몰 링크 — 확인 결과 (2026-10-27, 개발 PC에서 curl)
- 무신사 상품 페이지: `og:image`(상품 사진), `og:title`, JSON-LD `Product` 있음 → 동작 예상.
- 유니클로 KR 상품 페이지: `og:image`, `og:title` 있음 → 동작 예상.
- 29CM·지그재그·W컨셉: 임의 상품 번호로만 확인해 사이트 기본 이미지가 나옴 → **실제 상품 링크로 기기 확인 필요**.
- 기기에서 실제 링크로 왕복 테스트는 아직 안 함(미검증).

개인정보: 붙여 넣은 URL과 기기 IP가 해당 쇼핑몰에 전달됨(사용자가 그 링크를 연 것과 같음). WearLog 서버는 거치지 않고 쿠키·계정 정보도 보내지 않음.

## 인스타그램 — 선택지 검토
1. **Instagram API with Instagram Login (공식)** — 프로페셔널(비즈니스·크리에이터) 계정만 대상, Meta 앱 검수, 토큰 교환용 서버(클라이언트 시크릿은 앱에 넣을 수 없음) 필요. 개인 계정 사용자 대부분이 못 씀. Basic Display API는 2024-12-04 종료. → **보류**.
2. **인스타 페이지 읽기(스크래핑)** — 로그인 벽 + 이용약관 위반 소지 → **하지 않음**.
3. **OS 공유 시트로 받기 — 2026-10-27 구현(D-020)** — 인스타·갤러리·쇼핑몰 앱에서 "공유 → WearLog"로 이미지나 링크를 받아 옷 등록 화면을 바로 엶. Android intent filter + iOS Share Extension이 필요해 config plugin(예: share-intent 계열) 도입과 **development build** 필요. 이미지면 사진 경로, URL이면 위 링크 경로로 연결.
4. 여러 장 한 번에 선택해 차례로 등록(갤러리에 저장한 인스타 사진 묶음용) — Expo 내장 `allowsMultipleSelection`으로 가능, 다음 작업 후보.
